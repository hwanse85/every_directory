# 검색 결과 선택 시 탐색창 따라가기 설정 — 0.12.3

## 바뀐 점

- 이전에는 검색 결과를 한 번 클릭하거나 화살표·Home·End·PageUp·PageDown으로 옮길 때마다 활성 탐색창이 그 항목의 폴더로 이동했다. 보던 폴더가 검색할 때마다 바뀌었다.
- 이제 기본값은 **꺼짐**이다. 검색 결과를 선택해도 탐색창 위치는 그대로다.
- 설정 → 사용자 설정 → 검색 결과와 탐색의 **검색 결과 선택 시 탐색창 따라가기**를 켜면 이전처럼 동작한다.
- 이전 버전의 설정 파일에는 이 항목이 없으므로 업데이트하면 꺼짐으로 시작한다.

## 꺼짐일 때 위치를 여는 방법

- **Ctrl+Enter**(macOS는 ⌘+Enter): 선택한 검색 결과의 위치를 활성 탐색창에서 연다.
- **새 탭에서 열기**: 검색 결과 위 선택 표시줄의 단추로 활성 탐색창의 새 탭에서 연다.
- **폴더 더블클릭·Enter**: 폴더는 활성 탐색창에서 연다. 파일은 이전처럼 기본 앱으로 실행한다.

## 검증

- 단위 테스트: 기본값 꺼짐, 저장한 켜짐 값 유지, 잘못된 값은 꺼짐으로 정리(TypeScript). 이전 설정 파일은 꺼짐으로 읽음(Rust).
- 실제 앱 E2E(`ux`): 기본값에서 ↓로 검색 결과를 선택해도 모든 탐색창 위치가 그대로인지, 설정을 켜면 선택한 결과의 위치로 활성 탐색창이 이동하는지.
- 다른 E2E 스위트는 따라가는 흐름을 전제로 하므로 시작할 때 이 설정을 켜 둔다.
