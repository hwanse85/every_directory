# Windows 0.7.6 개선 및 검증

2026-10-24, Windows x64 / WebView2 / `codex/project-work`.

## 반영한 동작

- 메인 검색·빠른 검색·현재 폴더 필터에서 IME가 `ㄳ`, `ㄻ`, `ㅄ` 등으로 합친 독립 자음을 입력 도중 분리한다. `ㄲ`, `ㅆ` 등 된소리와 일반 한글 음절은 보존한다. 조합을 끝내고 다음 프레임에 초점을 복구하여 다음 글자가 앞 자음을 덮어쓰지 않게 했다.
- 복사·붙여넣기·외부 파일 가져오기·드래그 복사는 `보고서.txt`, `보고서 (1).txt`, `보고서 (2).txt` 순서로 저장한다. 파일 확장자, 폴더 이름의 점, 같은 작업에 포함된 중복 이름을 구분한다. 기존 파일은 교체하지 않는다. 이름 변경·압축·이동의 충돌은 기존대로 안내한다.
- 같은 폴더에서 잘라내기 후 붙여넣기는 원본을 유지한다. 앱 내부 잘라내기를 완료하면 Windows 파일 클립보드를 소비하며, 작업 도중 다른 내용을 복사했다면 새 클립보드는 보존한다. 외부 프로그램의 잘라내기 항목은 원본을 보존하여 복사한다.
- Windows 네이티브 파일 드롭을 켜고 앱 내부 드래그는 포인터로 처리한다. 탐색창 빈 공간은 현재 폴더, 폴더 행은 해당 하위 폴더를 목적지로 사용한다. 확인창에서 앱 내부 항목은 복사/이동을 고르고 외부 파일은 복사한다. Escape로 내부 드래그를 취소한다.
- IME 입력 중 파일 작업 키를 차단하고 검색 결과에 초점이 있을 때 활성 탐색창의 다른 파일을 조작하지 않는다.

텍스트 입력란에서는 Ctrl+C/X/V/A와 Delete가 텍스트 편집으로 동작한다. Delete는 OS 휴지통이나 영구 삭제가 아닌 앱의 복원 가능한 휴지통을 사용한다. 일반 파일 작업 Undo, Shift+Delete 영구 삭제, 앱에서 Windows 탐색기로 끌어 내보내기는 제공하지 않는다.

## 실제 입력 추가 확인

검증용 EXE와 테스트 파일을 `output/manual-verification`에 격리하고 `computer-use`의 SendInput으로 확인했다. 원래 실행 중인 사용자 앱은 종료하거나 변경하지 않았다.

1. 두벌식 키 `q → r → t`로 입력한 `ㅂㄱㅅ`가 겹받침 없이 표시되고 보고서를 검색한다.
2. 이어 `d`를 누르면 `ㅂㄱㅅㅇ`가 되며 앞의 `ㅅ`가 남는다. Backspace로 `ㅇ`을 지우면 보고서가 다시 검색된다.
3. `Shift+t → f → a → d → e`로 `ㅆㄹㅁㅇㄷ`를 입력하면 `쏠리마인드.txt`가 검색된다.
4. 검색 결과의 파일을 실제 마우스로 탐색창의 폴더 행에 끌어 놓고 복사하면 목적지 파일이 생성되고 원본 바이트도 보존된다.

외부 Windows 탐색기의 물리 OLE 드롭, 실제 SMB 인증/재연결, 여러 DPI/모니터, 로그인·재부팅 자동 시작, macOS 실기기는 이 결과에 포함하지 않는다. 외부 드롭 자동 검사는 Tauri 이벤트 전달 이후 경계를 검증한다.

## 배포

`npm run desktop:build:windows`로 검증 기능이 없는 Windows x64 NSIS 설치본을 생성한다. 일반 실행 EXE도 별도로 제공한다. `output/v0.7.6`의 배포 파일과 SHA-256 목록을 확인한다. 설치본의 기존 경량 정책에 따라 Microsoft Edge WebView2 Runtime이 설치된 Windows를 대상으로 한다.

최종 생성 확인: 설치본 `EveryDirectory-0.7.6-windows-x64-setup.exe` 2,777,798바이트, 실행 파일 `EveryDirectory.exe` 7,754,240바이트. 두 파일의 PE 제품/파일 버전은 `0.7.6`이다. 앱의 x64 PE 아키텍처와 배포 바이너리에 검증 스크립트/환경 변수 마커가 없는 것을 검사했다. 설치 프로그램을 실제로 설치하거나 사용자 설정을 교체하는 검사는 실행하지 않았다.

새 버전을 실행하기 전에 이전 버전을 트레이에서도 완전히 종료하고, 설정의 앱 정보가 `0.7.6`인지 확인한다. 이 문서는 Windows 탐색기의 모든 셸 확장 및 모든 단축키와의 동등성을 의미하지 않는다.
