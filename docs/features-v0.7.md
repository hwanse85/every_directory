# v0.7 트레이·파일 작업 공간

기준일: 2026-10-23. React + Tauri 2 + Rust 구조를 유지하며 OCR은 배포에서 제외한다. 기존 검색·파일 작업은 [v0.6 기준표](features-v0.6.md)를 계승한다.

## 이번 버전

| 구분 | 제공 기능 |
|---|---|
| 트레이 | 실행 시 아이콘 생성, 검색·창 열기·파일 도구·인덱스 관리·숨기기·완전 종료 메뉴 |
| 백그라운드 | 닫기 버튼은 기본적으로 창만 숨기며 인덱스 감시 유지. 계속 실행 여부는 설정과 트레이에서 변경·저장 |
| 전역 호출 | Mac `⌘⇧Space`, Windows `Ctrl+Shift+Space`. 다른 앱 위에서 창 복원 후 검색창 초점. 등록 충돌은 설정에 표시 |
| 중복 실행 | 추가 실행 시 기존 프로세스의 창과 검색창 복원 |
| 작업 공간 | 어두운 탐색 사이드바, 검색/탐색 계층, 활성 창 강조, 정돈된 탐색 도구 모음, 파일 종류 아이콘 |
| 화면 설정 | 라이트·다크·시스템 테마, 기본 43px/촘촘한 34px 목록, 설정 저장 |
| 우클릭 메뉴 | 각 작업 아이콘, 단축키, 구분선과 활성 조건. 다른 창·경로 복사·파일 도구·새로 만들기·보기의 5개 하위 메뉴 |
| 메뉴 키보드 | 위아래·Home/End, 좌우 하위 메뉴, Enter, Esc. 파일 행에서 Shift+F10. 메뉴 안에서도 표시된 주요 단축키 실행 |
| 생성·복제 | 새 텍스트 파일, 새 폴더, 같은 폴더 사본 생성. 기존 항목 덮어쓰기 차단, 연속 사본 자동 번호 |
| 두 창 파일 작업 | 다른 창에서 위치 열기, F5 복사/F7 이동, 원본·대상 폴더 확인 대화상자 |
| 경로 활용 | 이름·전체 경로·연결 루트 기준 상대 경로·Markdown 링크 복사, 현재 폴더에서 터미널 열기 |
| 보기 | 숨김 파일 표시 전환, 선택 반전, 전체 선택, 새로고침, 폴더 즐겨찾기, 파일 목록 CSV |
| 파일 도구 모음 | 일괄 이름 변경·중복 찾기·두 폴더 비교·용량 분석·이미지 변환·SHA-256·복제·다른 창 복사·ZIP 생성/해제·새 파일·휴지통 복원 12개 카드 |
| 용량 분석 | 하위 파일/폴더 수, 전체 바이트, 확장자별 용량, 큰 파일 30개, 결과 위치 열기 |
| 중복 찾기 | 같은 크기 후보를 스트리밍 SHA-256으로 검증. 중복 그룹과 회수 가능 용량, 각 파일 위치 열기 |
| 폴더 비교 | 상대 경로에 따라 파일을 대조하고 크기·SHA-256으로 내용 확인. 동일/내용 다름/한쪽만/미확인 구분과 필터 |

## 분석 한도

각 폴더 최대 100,000파일, 총 내용 읽기 4GiB, 실행 120초. 중복은 100그룹·1,000파일, 비교 차이는 1,000행까지 표시한다. 한도에 도달하면 부분 결과 또는 표시 제한을 명시한다. 읽지 못한 파일은 동일하다고 판정하지 않는다. 분석을 겹쳐 실행하지 않으며 취소할 수 있다. 링크와 앱 내부 폴더는 제외한다. 분석 도구는 파일을 자동 삭제·이동·동기화하지 않는다.

## 남은 범위

기능이 모든 Finder/Windows 탐색기·Everything/Q-Dir 기능을 대체한다고 표시하지 않는다. OS 외부 파일 클립보드와 외부 드래그, 셸 확장 메뉴, 일반 실행 취소·작업 큐·복사 중 취소, NTFS MFT/USN, 문서 본문 인덱싱, 압축 내부 탐색, 양방향 동기화 등은 아직 제공하지 않는다. 기존 기준표의 중복 파일 찾기 미구현 항목은 이번 버전에서 해소했다. Windows 실제 설치·기본 앱 연결과 트레이 동작은 Windows 환경에서 추가 검증해야 한다.

## 빌드

- macOS Apple Silicon: 앱, DMG, ZIP.
- Windows x64: NSIS 설치 EXE. WebView2가 없으면 공식 런타임 설치를 안내한다.
- 외부 Node 서버를 사용하지 않는다. 개발용 `smoke-test` 자동 검증 코드는 최종 배포 빌드에 포함하지 않는다.
- Mac은 로컬 임시 서명, Windows는 코드 서명 없이 생성한다. 상용 배포 인증서/Apple 공증은 별도 배포 작업이다.
