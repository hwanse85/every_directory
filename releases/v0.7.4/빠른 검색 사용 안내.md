# 빠른 파일 검색

macOS와 Windows 데스크톱 앱에서 같은 검색·파일 작업 흐름을 제공합니다.
앱을 실행한 뒤 단축키를 누르거나 트레이 메뉴의 **빠른 파일 검색**을 선택하세요.
메인 창 상단의 검색 아이콘으로도 호출할 수 있습니다.

| 작업 | macOS | Windows |
|---|---|---|
| 검색창 표시·숨김 | Command+Shift+Space | Ctrl+Shift+Space |
| 결과 선택 | ↑ / ↓ | ↑ / ↓ |
| 기본 앱 또는 폴더 열기 | Enter | Enter |
| Finder / 탐색기에서 항목 선택 | Command+Enter | Ctrl+Enter |
| 작업 메뉴 | Tab | Tab |
| 파일·폴더를 OS 클립보드에 복사 | Command+C | Ctrl+C |
| 전체 경로 복사 | Command+Shift+C | Ctrl+Shift+C |
| 작업 메뉴에서 뒤로 / 창 숨김 | Esc | Esc |

검색어를 선택한 상태에서는 일반적인 텍스트 복사 동작을 유지합니다.
한글 조합 중인 Enter와 탐색 키는 파일 작업을 실행하지 않습니다.

## 검색과 바로가기

- 앱에 연결한 폴더의 파일명과 폴더명을 검색합니다. 문서 본문을 검색하지는 않습니다.
- 한글 초성은 자동 인식하며 `*`, `?` 와일드카드도 사용할 수 있습니다.
- 연결 폴더와 파일 종류를 필터로 좁힐 수 있습니다.
- 이름의 정확한 일치와 앞부분 일치를 우선하고, 같은 조건에서는 즐겨찾기와 최근 사용 항목을 먼저 표시합니다.
- 결과는 최대 12개 표시합니다. 시간 제한에 도달하면 일부 결과임을 안내합니다.
- 빈 검색창에는 즐겨찾기 파일·폴더, 최근 사용 항목과 최근 검색어가 표시됩니다.
- 작업 메뉴에서 즐겨찾기를 추가·해제합니다. 메인 탐색기와 두 창의 기록은 즉시 동기화됩니다.
- 메인 탐색기의 파일·폴더 우클릭 메뉴에서도 즐겨찾기를 추가·해제할 수 있습니다.
- 최근 검색어는 20개, 최근 사용 위치는 30개까지 저장합니다. 검색창의 최근 기록 지우기는 즐겨찾기를 유지합니다.

## 파일 작업

**파일·폴더 복사**는 경로 문자열과 다릅니다. macOS는 파일 URL, Windows는 CF_HDROP 목록으로 OS 클립보드에 기록합니다. Finder 또는 탐색기의 대상 폴더에서 붙여넣으면 파일 사본이 생성됩니다. 다른 앱의 첨부 파일 붙여넣기는 대상 앱의 지원에 따라 달라집니다.

**다른 폴더로 복사**에서는 앱에 연결한 폴더 안에서 대상을 고릅니다. 복사를 실행하기 전에 대상 경로를 표시하고, 기존 항목을 덮어쓰지 않습니다. 연결하지 않은 곳으로 복사하려면 OS 클립보드의 붙여넣기를 사용하거나 대상 폴더를 먼저 연결하세요.

**Every Directory에서 위치 열기**는 메인 탐색기의 해당 폴더로 이동하고 파일을 선택합니다. **Finder / 탐색기에서 보기**는 운영체제의 파일 관리자를 엽니다.

## 설정과 실행

설정의 **전역 검색 단축키** 입력란에서 수정 키를 포함한 새 조합을 누르고 **적용**합니다. 등록 충돌이나 저장 실패가 발생하면 기존 단축키를 유지합니다.

창을 닫은 뒤에도 호출하려면 **창을 닫아도 계속 실행**을 사용하세요. 앱을 완전히 종료하면 전역 단축키도 해제됩니다. 빠른 검색창은 Esc 또는 다른 앱을 클릭하면 숨겨집니다. Esc로 취소할 때 직전 앱으로 초점을 돌립니다.

검색 색인은 메인 탐색기와 공유합니다. 인터넷 연결 없이 작동하며, 네트워크 공유 폴더의 실제 파일을 열거나 복사할 때는 해당 업무망 연결과 파일 접근 권한이 필요합니다.

## 검증 범위

공통 UI와 엔진 자동 테스트, macOS 네이티브 WebView 실행, macOS 파일 URL 기록, Windows UTF-16 파일 목록 인코딩, Windows MSVC 대상 컴파일을 검증합니다. Windows 실제 단축키 호출·탐색기 붙여넣기와 macOS 전체 화면·다중 Spaces 조합은 각 운영체제 실기 검증 항목으로 남깁니다. 기존 GitHub Actions의 macOS·Windows 데스크톱 빌드 작업에서도 Rust 테스트와 설치 파일 빌드를 수행합니다.
