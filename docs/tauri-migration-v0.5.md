# Tauri 전환 검증 기록 — v0.5.0

검증일: 2026-10-23. 환경: macOS 27.0.1 / Apple Silicon arm64 / Rust 1.99.1 / Node.js 26.9.0.

## 적용한 구조

React 화면을 유지하고 Tauri 2의 IPC로 Rust 엔진을 호출한다. 검색, 디스크 감시, 파일 작업, ZIP, 이미지 변환, 파일 미리보기 전송을 Rust로 옮겼다. 설치 앱은 Node.js와 localhost HTTP 서버를 실행하지 않는다. Windows 빌드에는 WebView2 설치 구성을 포함하고, Mac은 WKWebView를 사용한다.

왼쪽 검색과 오른쪽 탐색창의 기본 구성을 유지했다. 기본 탐색창은 두 개이며 1~4개, 창별 독립 탭, 검색 위치 네 방향, 좌우·위아래·격자 배치와 경계 비율 조절을 지원한다. 첫 번째 탐색창을 기본 활성화하고 파란 테두리와 활성 표시를 사용한다. 검색 결과 한 번 클릭은 활성 창에 위치와 파일 선택을 표시하며, 더블클릭은 기본 앱 실행 명령에 연결한다.

화면에서는 큰 홍보 문구, 장식 배지, 여러 강조색을 줄였다. 중성 배경, 한 가지 파란 강조색, 얇은 경계선과 간결한 파일 도구 모음을 적용했다. OCR 엔진과 언어 모델은 데스크톱 배포에서 제외하고 기존 웹 실행 경로에 보존했다.

## 자동 검증

| 구분 | 결과 | 확인 범위 |
|---|---|---|
| TypeScript / Vite 프로덕션 빌드 | 통과 | 프런트엔드 타입 검사와 번들 생성 |
| Rust 파일 엔진 | 12개 통과 | 다섯 검색 방식, 필터, 복사·이동·이름 변경·새 폴더, 대소문자 이름 변경, ZIP, 휴지통·복원, SHA-256, 이미지 변환, 영속화, 변경 감시, 경로·링크·덮어쓰기 차단, 범위 응답, 사본 저장 |
| 별도 릴리스 검색 벤치마크 | 1개 통과 | 20만 개 메타데이터와 부분 결과 여부 |
| 기존 Node 웹 테스트 | 24개 통과 | 기존 서버·검색·파일 작업·OCR 호환 경로 |
| 실제 Tauri WebView 통합 | 9개 통과, 수집 오류 없음 | 아래 상세 항목 |

Rust 테스트의 벤치마크 한 개는 일반 테스트 실행 시 의도적으로 제외되며 별도 릴리스 명령으로 실행했다.

Tauri 통합은 `smoke-test` 기능으로 빌드한 실제 WKWebView와 내장 프런트엔드 자산, 실제 Rust IPC·파일 프로토콜을 사용했다. 전용 검증 데이터와 실제 TXT·PNG·3페이지 PDF 파일로 다음을 확인했다.

1. Tauri IPC 초기화
2. 기본 두 탐색창과 첫 번째 창 활성 상태
3. 검색 클릭으로 활성 탐색창의 위치 및 파일 선택 표시
4. 두 번째 창 활성화 후 검색 결과 연결
5. `edfile` 범위 응답과 한글 텍스트 미리보기
6. PDF 워커, CSP 및 실제 PDF 캔버스 렌더링
7. 실제 이미지 미리보기
8. 탐색창별 독립 탭
9. 탐색창 1·3·4·2개 전환

화면이 잠긴 환경에서는 WebView 실행이 지연됐다. 통합 검증 빌드에서만 백그라운드 제한을 해제해 검증했다. 이 설정과 자동 검증용 보고 명령은 기본 배포 빌드에 포함되지 않는다. 결과 원본: `output/playwright/tauri-review/native-final-data/smoke-report.json`.

실제 파일 작업은 독립된 임시 폴더에서 검증했다. OS 폴더 선택·사본 저장 대화상자, OS 파일 연결 실행, Mac 공개 배포 서명·공증 및 Windows 실기기 설치는 이번 자동 검증 범위에 포함되지 않는다. Windows용 CI 구성은 추가했지만 실행 결과는 아직 없다.

## 검색 성능

메모리에 인덱싱한 가상 메타데이터 200,000개 기준, Rust 릴리스 빌드 측정이다. 디스크 스캔, UI 입력 대기 및 IPC 전달 시간은 이 표에 포함하지 않는다. 각 검색은 부분 결과 없이 완료됐다.

| 방식 | 검색어 | 엔진 시간 | 결과 수 |
|---|---|---:|---:|
| 일반 | `보고서` | 4.31ms | 200,000 |
| 와일드카드 | `*0199*.pdf` | 0.28ms | 140 |
| 정규식 | `보고서_0199\d{2}\.pdf$` | 74.23ms | 100 |
| 초성 | `ㅂㄱㅅ` | 48.94ms | 200,000 |
| 퍼지 | `프러젝트` | 171.50ms | 200,000 |

이 결과는 해당 데이터와 검색어의 측정값이다. 모든 규모·정규식에서 1초를 보장하는 근거는 아니다. 650ms 제한에 도달하면 화면에 부분 결과임을 표시한다.

재현 명령:

```sh
npm run test:rust -- --release --test engine benchmark_two_hundred_thousand_entries -- --ignored --nocapture
```

## 배포본

Apple Silicon용 Mac 앱 번들은 약 5.84MiB, DMG는 약 3.42MiB, ZIP은 약 2.91MiB다. 로컬 검증용 임시 서명과 번들 무결성 검사를 적용했으며 Developer ID 서명·공증은 별도다. 최종 바이트 크기와 SHA-256은 `output/playwright/tauri-review/build-artifacts.json`에 기록한다. 앱 데이터와 생성 이후 인덱스 용량은 별도다. Windows용 실제 용량은 Windows 빌드 이후 측정해야 한다.

```sh
npm run desktop:build -- --bundles app
npm run desktop:package:mac
```

출력 폴더: `src-tauri/target/release/bundle/macos/`, `src-tauri/target/release/bundle/dmg/`.

## 화면 기록

`output/playwright/tauri-review/index.html`에서 9개 화면을 확인할 수 있다. 스크린샷은 같은 React 화면을 **Chromium 브라우저와 기존 localhost 백엔드**에서 촬영했다. Tauri 창 자체의 스크린샷은 아니다. 네이티브 통합 통과 근거는 위의 별도 WebView 보고서다.

## 남은 기능 범위

파일 클립보드는 앱 내부 탐색창 사이에서 공유한다. OS 파일 클립보드, OS 탐색기의 확장 메뉴, 일반 실행 취소, 폴더 비교·동기화는 아직 구현하지 않았다. 삭제는 앱 전용 휴지통이며 OS 휴지통과 별개다. ZIP은 최대 10,000항목·500MB 해제, 이미지 변환은 정지 PNG/JPEG/WebP와 사본 저장을 기준으로 한다. 모든 PowerToys 기능이 구현된 것으로 해석해서는 안 된다.
