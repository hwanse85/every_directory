# Every Directory

로컬 파일 검색과 다중 탐색창을 결합한 **React + Tauri 2 + Rust 데스크톱 앱**입니다. Windows와 macOS용 빌드 구성을 제공합니다. 배포 앱은 Node.js나 HTTP 서버 없이 실행됩니다.

현재 0.7.6 소스는 [Windows 호환성 개선](docs/windows-compatibility.md), [초성 입력·번호 사본·Windows 단축키·드롭 및 E2E 검증](docs/e2e-v0.7.6.md), [앱 정보·라이선스 고지 구분](docs/licensing.md)을 포함합니다. 이전 배포 파일에는 새 변경이 소급 반영되지 않습니다.

## 실행

0.7.6 Windows 설치본 빌드와 검증 범위는 [0.7.6 안내](docs/e2e-v0.7.6.md)를 참고하세요. 기존에 저장된 배포 파일은 [v0.7.4 배포 안내](docs/releases-v0.7.4.md)에 남아 있습니다.

빌드된 macOS 앱은 `src-tauri/target/release/bundle/macos/Every Directory.app`, 설치 이미지는 `src-tauri/target/release/bundle/dmg/`에 생성됩니다. Windows 빌드는 `.msi` 또는 `-setup.exe`를 생성합니다. 각 운영체제와 CPU에 맞는 파일을 사용합니다.

개발 환경에는 Node.js 22.13 이상, Rust stable, 각 OS의 [Tauri 빌드 도구](https://v2.tauri.app/start/prerequisites/)가 필요합니다. 배포 파일을 사용하는 사용자는 Node.js나 Rust를 설치하지 않습니다.

```sh
npm ci
npm run desktop:dev
```

```sh
npm run desktop:build
```

화면 잠금이나 CI에서 Finder 자동화 없이 Mac 설치 파일을 만들려면 다음 명령을 사용합니다. 같은 폴더에 DMG와 ZIP을 생성합니다.

```sh
npm run desktop:build -- --bundles app
npm run desktop:package:mac
```

Windows x64 설치 EXE는 다음 명령으로 빌드합니다. macOS 교차 빌드에는 `cargo-xwin`, LLVM/LLD, NSIS와 `x86_64-pc-windows-msvc` Rust 타깃이 필요합니다. Windows에서는 기본 Rust MSVC 도구를 사용합니다.

```sh
npm run desktop:build:windows
```

Windows 10·11의 64비트(x64) 환경을 대상으로 빌드합니다. v0.7.4 기본 설치본은 WebView2 런타임을 포함하거나 다운로드하지 않는 경량 설치본입니다. PC에 WebView2가 없으면 전산 담당자가 오프라인 런타임을 먼저 설치해야 합니다. 자세한 내용은 [배포 안내](docs/releases-v0.7.4.md)를 참고하세요. Mac은 운영체제의 WKWebView를 사용합니다. Mac 빌드는 임시 서명을 적용한 로컬 배포본이며 Apple 공증은 하지 않았습니다. Windows 0.7.6은 실제 WebView2·파일 작업·클립보드·키보드 및 IME 입력을 검증합니다. 세부 범위와 제외 항목은 0.7.6 검증 기록을 참고하세요.

## 사용 방법

1. **폴더 연결**에서 운영체제 폴더 선택 대화상자로 검색할 폴더를 등록합니다.
2. 검색 결과를 **한 번 클릭하면 활성 탐색창에 위치와 선택 항목을 표시**하고, **더블클릭하면 기본 앱으로 실행**합니다.
3. 탐색창은 기본 두 개입니다. 1~4개로 변경하고 각 창에 여러 탭을 열 수 있습니다. 클릭하거나 F6으로 활성 창을 바꿉니다.
4. **레이아웃**에서 검색 위치, 탐색창 배치와 비율을 바꿉니다. 경계선 드래그와 방향키로 크기를 조절할 수도 있습니다.
5. 파일 선택 후 도구 모음에서 복사·잘라내기·붙여넣기·이름 변경·삭제·압축을 실행합니다. 추가 도구에는 일괄 이름 변경, 미리보기, 이미지 변환, 속성·SHA-256과 휴지통 복원이 있습니다.
6. 탐색창에서도 파일 더블클릭은 기본 앱 실행입니다. 폴더 트리·현재 폴더 필터·열 정렬·우클릭 메뉴와 창 사이 드래그 복사/이동을 사용할 수 있습니다.
7. 검색 조건과 탭·창 조합은 사이드바 +로 저장하고 검색 결과는 CSV로 내보낼 수 있습니다.
8. Space로 미리보기를 열고 Ctrl/⌘ Shift P로 명령을 검색합니다. PDF는 페이지 이동과 확대를 지원합니다.
9. 앱을 실행하면 Mac 메뉴 막대 / Windows 트레이에 아이콘을 표시합니다. 기본적으로 창을 닫아도 실행을 유지합니다. 트레이 메뉴나 `⌘⇧Space` / `Ctrl+Shift+Space`로 다시 열고 검색할 수 있습니다. 트레이의 **완전히 종료**로 프로세스를 종료합니다.
10. 우클릭 메뉴는 아이콘·단축키와 5개 하위 그룹을 제공합니다. Windows에서는 F5로 현재 목록을 새로고침하고 Shift+F5/F7로 다른 탐색창으로 복사/이동합니다. macOS는 F5/F7로 복사/이동합니다. Ctrl/⌘ D는 사본 생성입니다. **파일 도구**에서 중복 파일 찾기·용량 분석·두 폴더 비교를 실행합니다. 설정에서 라이트/다크/시스템 테마와 목록 밀도를 선택할 수 있습니다.
11. 검색 결과 위 **표시 항목**에서 위치·유형·확장자·크기·수정일·연결 폴더·전체 경로를 선택합니다. 이름은 항상 표시하며 선택한 열은 자동 저장합니다. 열 제목을 누르면 정렬하고, 열이 많으면 가로로 스크롤합니다. **기본값**으로 이름·위치·크기·수정일 구성을 복원합니다.
12. 우클릭 메뉴에서 화살표가 있는 항목에 마우스를 올리면 하위 메뉴가 바로 옆에 펼쳐집니다. 다른 항목으로 이동해 메뉴를 바꾸거나, →/←로 진입·복귀할 수 있습니다. Esc는 하위 메뉴부터 닫습니다.

## 검색

일반 포함 검색·공백 AND·따옴표 구문·`ext:pdf,docx`, 와일드카드 `* ?`, 정규식, 오타 허용 퍼지, 한글 초성 검색을 지원합니다. 대소문자와 파일명/전체 경로, 폴더 및 파일 분류 필터를 제공합니다.

v0.7.4의 기본값은 **초성 + 일반 검색**입니다. `ㅂㄱㅅ`, `보고서`, `보고ㅅ`, `*.pdf`를 한 모드에서 처리하며 IME가 합친 자음도 분리합니다. 설정에서 기본 검색 방식, 로그인 자동 시작(기본 켜짐), 트레이 시작과 전역 단축키를 바꿀 수 있습니다. 탐색창 탭은 색상 미지정으로 시작합니다. 팔레트 버튼으로 색상을 지정하고 옆의 색상 해제 버튼으로 되돌립니다. 새 탭은 기존 탭의 색을 상속하지 않습니다.

Ctrl/⌘+L 또는 Alt+D로 실제 폴더 주소를 입력하고, 연결된 다른 폴더의 절대 경로로 이동할 수 있습니다. Alt+←/→/↑는 뒤로/앞으로/상위 폴더, Ctrl/⌘+T/W는 새 탭/현재 탭 닫기입니다. 연결 폴더 밖의 위치는 먼저 연결해야 합니다.

v0.7.1부터 **한글 초성** 모드에서는 파일명과 검색어의 띄어쓰기 차이를 무시합니다. `데이터분석 발굴.pdf`는 `ㄷㅇㅌㅂㅅ ㅂㄱ`, `ㄷㅇㅌㅂㅅㅂㄱ`, `ㄷㅇ ㅌㅂㅅㅂ ㄱ`로 모두 찾습니다. 공백으로 나눈 검색어는 기존처럼 AND로 적용하며 따옴표 안의 공백도 무시합니다. 일반 검색과 정규식의 공백 처리는 유지합니다.

v0.6 데스크톱은 OR `|`, 제외 `!`, 그룹 `< >`, `file:`, `folder:`, `path:`, `size:>10mb`, `size:1mb..10mb`, `dm:today`, `dm:>=2026-01-01`도 지원합니다. OR를 AND보다 먼저 계산합니다. 처음 실행해 연결 폴더가 없으면 폴더 연결 안내를 표시하며 실행할 수 없는 샘플 파일을 표시하지 않습니다.

Rust `regex` 엔진을 사용하며 전후방 탐색과 역참조는 지원하지 않습니다. 정규식·일괄 치환의 모든 문법이 기존 RE2JS와 동일하지는 않습니다. 검색은 NFC 한글 정규화를 적용합니다.

검색 목표는 인덱싱 완료 후 1초 이내입니다. 엔진이 650ms 한도를 넘으면 부분 결과임을 표시합니다. 검색어와 파일 규모에 따른 성능은 실제 데이터로 검증해야 하며 첫 인덱싱 시간은 별도입니다.

## 파일 작업과 범위

- 등록한 폴더 안의 인덱싱된 파일만 작업합니다. 심볼릭 링크와 `.git`, `node_modules`, 내부 작업·휴지통 폴더는 인덱싱에서 제외합니다.
- 복사·이동·일괄 이름 변경에서 기존 대상 파일을 덮어쓰지 않습니다. 루트 및 다른 연결 폴더의 상위 항목은 변경하지 않습니다. 복사·이동 대상이 원본 내부인 경우 거부합니다.
- 파일 작업은 직렬로 처리하고 변경 경로를 갱신합니다. OS 감시에서도 변경된 경로를 모아 증분 갱신합니다. 여러 항목 중 일부가 완료된 후 다음 항목에서 오류가 날 수 있습니다.
- 삭제는 OS 휴지통이 아닌 루트의 `.every-directory-trash`에 보관합니다. 앱에서 복원할 수 있으며 원래 상위 폴더가 있어야 합니다. 복원 대상이 이미 있으면 중단합니다.
- 탐색창과 빠른 검색창은 OS 파일 클립보드로 복사할 수 있습니다. Finder·Windows 탐색기에서 복사한 외부 파일도 앱에 사본으로 붙여넣습니다. 앱 내부 잘라내기는 OS 클립보드의 항목과 일치할 때 이동합니다. 탐색기의 확장 메뉴·일반 실행 취소·폴더 동기화는 현재 구현 범위에 포함되지 않습니다. 파일 이름·절대/상대 경로·Markdown 링크는 OS 클립보드로 복사합니다.
- 폴더 용량 분석·SHA-256 기반 중복 찾기·두 폴더 파일 내용 비교를 제공합니다. 분석은 10만 파일·내용 읽기 4GiB·120초로 제한하고 한도·읽기 제외를 결과에 표시합니다. 분석 중 취소할 수 있으며 파일은 변경하지 않습니다. 비교는 파일 기준이며 빈 폴더·권한·확장 속성을 비교하지 않습니다.
- ZIP 생성·해제와 PNG/JPEG/WebP 이미지 크기 변경을 지원합니다. ZIP 해제는 새 폴더에 최대 10,000개·500MB까지 수행하고 경로 탈출과 링크를 거부합니다. 암호화 ZIP은 지원하지 않습니다.
- 이미지 크기 변경은 새 폴더의 사본에만 적용합니다. 파일당 50MB·4천만 화소, 출력 최대 8192px·4천만 화소, 한 번에 50개입니다. 정지 이미지와 기본 비율 유지·확대 금지를 기준으로 제공합니다. JPEG 투명 영역 등 코덱별 결과는 확인해야 합니다.
- 텍스트·이미지·PDF·OS가 재생 가능한 미디어를 미리 볼 수 있습니다. 한 번의 파일 읽기는 256MB까지, 텍스트는 앞 256KB를 표시합니다. 데스크톱에서는 **사본 저장**으로 새 경로에 저장합니다.
- 데스크톱 빌드에서는 OCR 엔진과 언어 모델을 제외했습니다. 기존 웹 버전의 OCR 코드는 별도로 남아 있습니다.

## 저장과 기존 데이터

인덱스는 OS 앱 데이터 폴더(`com.everydirectory.desktop`)에 보관합니다. `EVERY_DIRECTORY_DATA`로 다른 위치를 지정할 수 있습니다. 기본 위치에서 처음 실행하면 기존 `~/.every-directory/index.json`을 복사해 연결 폴더를 가져옵니다. 기존 웹 서버의 데이터는 수정하지 않습니다. 화면 설정은 앱 WebView에 저장되어 기존 브라우저의 배치·탭 설정과 별개입니다.

## 검증

v0.7.2의 검색 속성 선택·호버 하위 메뉴와 최신 배포 파일은 [검색 열·메뉴 검증 기록](docs/verification-v0.7.2.md)에 정리했습니다. v0.7.1 초성 검색의 공백 처리는 [초성 검색 검증 기록](docs/verification-v0.7.1.md)을 참고하세요.

v0.7의 트레이·화면·파일 도구 변경은 [기능 기준표](docs/features-v0.7.md), 테스트와 배포 파일 검증은 [v0.7 검증 기록](docs/verification-v0.7.md)에 정리했습니다. 이전 검색·파일 기능과 남은 차이는 [v0.6 기준표](docs/features-v0.6.md)를 참고하세요.

v0.5 전환의 실측 성능, 실제 WebView 검증과 남은 범위는 [전환 검증 기록](docs/tauri-migration-v0.5.md)에 정리했습니다.

```sh
npm run build
npm run test:rust
npm test
```

20만 항목 검색 벤치마크:

```sh
npm run test:rust -- --release --test engine benchmark_two_hundred_thousand_entries -- --ignored --nocapture
```

Rust 검증은 실제 임시 파일로 검색 방식, 기본 파일 작업, ZIP, 이미지 변환, 경로 차단, 덮어쓰기 방지, 감시 갱신과 미리보기 범위 응답을 확인합니다. 기존 Node 테스트는 웹 호환 경로를 확인합니다. `.github/workflows/desktop.yml`은 Mac·Windows 테스트 및 설치 파일 빌드를 구성합니다. 설정이 있다는 사실만으로 CI 실행을 확인한 것은 아닙니다.

실제 WebView에서 검색 위치 표시·활성 창·탭·미리보기를 검증하는 선택 기능도 제공합니다. `smoke-test`는 기본 배포 빌드에 포함되지 않습니다. `EVERY_DIRECTORY_DATA`는 전용 검증 폴더, `EVERY_DIRECTORY_SMOKE_ROOT`는 `문서/업무 보고서 2026.txt`, `문서/개발 계획.pdf`(3페이지), `이미지/작업 화면.png`가 있는 테스트 폴더로 지정합니다.

```sh
npm run desktop:build -- --debug --no-bundle --features smoke-test
```

환경 변수를 지정한 상태에서 `src-tauri/target/debug/every-directory`를 실행하면 검증 폴더의 `smoke-report.json`에 결과를 기록합니다. `stage: started`만 있는 기록은 통과가 아닙니다. 운영체제 잠금 등으로 WebView 실행이 지연되면 잠금을 해제한 상태에서 다시 확인해야 합니다.

## 기존 브라우저 버전

```sh
npm run dev:web
```

`http://127.0.0.1:5173/`에서 이전 Node 서버와 같은 React 화면을 사용할 수 있습니다. 이 선택 실행 경로에는 Node.js가 필요합니다. 데스크톱 배포에는 Node 서버와 npm 의존성 폴더를 넣지 않습니다. 자세한 기존 기능과 검증 기록은 [웹 버전 기록](docs/legacy-web.md)을 참고하세요.

## 빠른 파일 검색

macOS의 `Command+Shift+Space`, Windows의 `Ctrl+Shift+Space`로 독립 검색창을 호출합니다. 파일·폴더 열기, Finder/탐색기에서 보기, OS 파일 복사, 경로 복사, 연결 폴더로 복사, 즐겨찾기와 최근 기록을 지원합니다. 설정에서 단축키를 변경할 수 있습니다. 자세한 사용법과 검증 범위는 [빠른 검색 안내](docs/quick-search.md)를 참고하세요.
