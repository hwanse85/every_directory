# v0.6 기능 기준과 남은 차이

기준일: 2026-10-23. Everything과 Q-Dir의 주요 사용 흐름을 React + Tauri + Rust에서 제공하는 것을 목표로 한다. 원본 프로그램의 전체 기능과 Windows 셸 확장까지 동일하게 구현했다는 의미는 아니다. OCR은 사용자 요청에 따라 데스크톱에서 제외한다.

## 검색 예

- `보고서|계획 !초안 ext:pdf,docx`: 보고서 또는 계획이면서 초안을 제외한다.
- `file: size:1mb..10mb dm:>=2026-01-01`: 1~10MiB 파일 중 지정 날짜 이후 수정한 파일.
- `folder: path:프로젝트`: 경로에 프로젝트가 포함된 폴더.
- `!<alpha|beta> *.txt`: alpha와 beta를 모두 제외하는 TXT 파일.
- `dm:today`, `dm:yesterday`, `dm:2026-01-01..2026-12-31`: 현지 시간 기준 날짜 조건.
- 크기의 KB/MB/GB는 1024 배수를 사용한다. 날짜 범위 양 끝을 포함한다.

고급 연산자는 Rust 데스크톱 검색 엔진에 적용한다. 기존 Node 웹 서버의 검색 문법은 v0.5 범위를 유지한다.

## 원본과의 남은 차이

| 항목 | 현재 상태 / 다음 구현 범위 |
|---|---|
| Finder·Windows 탐색기와 파일 클립보드 교환 | 앱 내부 클립보드와 OS 경로 텍스트 복사 지원. 외부 파일 복사·잘라내기 교환은 미구현 |
| OS 외부 드래그·드롭 / 셸 확장 메뉴 | 앱 내부 창 사이 파일 드래그 지원. Finder·탐색기에서 드래그, Windows 확장 메뉴는 미구현 |
| 일반 실행 취소·작업 큐·충돌 선택 | 앱 휴지통 복원과 이름 충돌 거부 지원. 복사/이동 취소·재개·덮어쓰기 선택은 미구현 |
| 검색 결과 전체에 대한 정렬·내보내기 | 현재 최대 1,000개 표시 범위. 전체 결과 페이지 처리와 전체 내보내기는 미구현 |
| 본문·문서 속성 검색 | 현재 파일명/경로·크기·수정일 검색. PDF/Office 본문 인덱스·속성·중복 파일 찾기는 미구현 |
| 모든 Everything 한정자·함수·매크로 | 문서화된 위 문법만 지원. 전체 단어·접두/접미 옵션, 날짜 상대 범위 전체와 사용자 매크로 등은 미구현 |
| Windows MFT/USN 직접 인덱싱 | 크로스플랫폼 폴더 스캔과 OS 변경 감시 사용. NTFS 서비스·USN 직접 추적은 미구현 |
| 셸 가상 폴더·FTP·압축 내부 탐색 | 연결한 디스크 폴더와 ZIP 생성/해제만 지원. OS 특수 폴더·FTP·ZIP을 폴더처럼 탐색하는 기능은 미구현 |
| Q-Dir 사용자 지정 색상·열·인쇄·파일 연결 규칙 | 파일 종류 아이콘, 기본 앱 실행 지원. 사용자 색상 규칙·열 구성 저장·전용 인쇄·내부 연결 규칙은 미구현 |
| 네트워크·외장 볼륨 | OS에 마운트된 실제 폴더는 연결 가능. 오프라인·재연결·대규모 네트워크 감시 검증은 미완료 |
| Windows 실기기 | 빌드 및 CI 구성은 존재. 이번 검증은 macOS에서 수행하며 Windows 설치·PDF 연결 실행 결과와 구분 |

전체 기능 동등성이 완료된 것으로 표시하지 않는다. 후속 기능은 파일 열기와 기존 파일 작업이 안정적으로 동작하는 상태를 유지하면서 위 차이를 줄이는 방향으로 개발한다.
