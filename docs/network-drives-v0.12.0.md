# 네트워크·웹 드라이브 색인과 탐색 편의 개선 — 0.12.0

## 네트워크·웹 드라이브 색인

| 종류 | Windows | macOS |
|---|---|---|
| 네트워크 드라이브(SMB) | `\\서버\공유\폴더`, 연결한 드라이브(`Z:\`), `smb://서버/공유` | `smb://서버/공유`, `/Volumes/공유` |
| WebDAV | `https://서버/경로` → `\\서버@SSL\DavWWWRoot\경로`(WebClient 서비스) | `https://서버/경로`(Finder 서버 연결과 같은 방식) |
| AFP·NFS | 탐색기에서 드라이브로 연결한 뒤 선택 | `afp://`, `nfs://` |
| 클라우드 폴더 | OneDrive·Google Drive·Dropbox·iCloud 폴더 | `~/Library/CloudStorage`, iCloud Drive |
| 이동식 디스크 | USB·광학 드라이브 | 외장 볼륨 |

- **인덱스 관리 → 네트워크·웹 드라이브 연결**에 경로나 주소를 입력하면 운영체제 로그인 창으로 연결한 뒤 색인한다. Windows는 `WNetAddConnection3W`(자격 증명 창), macOS는 `mount volume`(Finder 서버 연결)을 쓴다. 비밀번호가 든 주소는 받지 않고 운영체제 창에서 입력한다.
- WebDAV·일부 네트워크 리디렉터에서 경로 정규화(`canonicalize`)가 실패해 연결이 거부되던 문제를 고쳤다. 존재를 확인한 뒤 절대 경로로 쓴다.
- 연결 폴더마다 드라이브 종류(로컬·네트워크·WebDAV·클라우드·이동식)와 갱신 방식을 표시한다.
- 네트워크·WebDAV 드라이브는 실시간 알림이 다른 PC의 변경을 놓칠 수 있어, 실시간 감시를 시도하면서 **5분마다 다시 확인**한다. 한 번 읽는 데 오래 걸리면 간격을 최대 60분까지 늘린다. 연결이 끊기면 마지막 색인을 유지하고 다시 연결되면 자동으로 갱신한다.
- 끊긴 네트워크 경로 때문에 앱 시작이 멈추지 않도록 원격 경로는 시작 시 정규화를 건너뛰고 감시 등록을 백그라운드에서 한다.
- 클라우드 폴더는 파일 내용을 내려받지 않고 이름·크기·날짜만 색인한다.

## 탐색 편의

- **폴더 진입 시 체크 오류 수정**: 0.11.0에서 폴더에 들어가면 키보드 커서를 주려고 첫 항목을 선택해 체크박스가 체크됐다. 이제 탐색기처럼 첫 항목에 초점만 두고, 첫 ↑↓로 그 항목을 선택한다. 상위로 올라오면 방금 나온 폴더를 선택하는 동작은 유지한다.
- **검색 → 탐색창 Tab 이동**: 검색창이나 검색 결과에서 Tab을 누르면 탐색창 1 → 2 → … 목록으로, 마지막 탐색창에서는 검색창으로 돌아간다. Shift+Tab은 반대 방향이다. 옮긴 탐색창이 활성 탐색창이 된다.
- **빠른 검색 경로 이동**: `C:\자료\업무 자료\프로젝트`, `\\nas\공유\업무`, `/Users/me/Projects/app`, `업무 자료\프로젝트`(연결 폴더 이름부터), `프로젝트/보고서`(일부 경로)를 입력하면 그 위치를 **경로 일치** 항목으로 맨 위에 보여 주고 Enter로 Every Directory 탐색창에서 연다. 그 아래에는 경로 아래 항목을 보여 준다. 연결 폴더 밖의 경로는 안내를 표시한다.
- **탐색창 3개 이상에서 트리**: 창 높이가 낮아 `보기 ▾` 메뉴 아래쪽(폴더 트리 항목)이 탐색창 밖으로 잘려 누를 수 없던 문제를 고쳤다. 메뉴는 화면 기준 위치에 띄우고 공간이 부족하면 위로 연다. 폴더 트리는 명령 막대의 **트리** 단추로 바로 켠다.

## 검증

- 단위 테스트: 경로 해석(절대·연결 폴더 이름·상대·연결 밖), 네트워크 주소 변환(SMB→UNC, WebDAV→DavWWWRoot, macOS 마운트 주소), 원격 경로 판별, 드라이브 종류 기록.
- macOS 실제 앱 E2E: 폴더 진입 시 선택·체크 없음과 첫 ↓ 선택, Tab 순환과 활성 탐색창, 탐색창 3개에서 메뉴가 화면 안에 표시·세 번째 탐색창 트리, 빠른 검색 절대 경로·연결 폴더 이름 경로 일치.
- Windows는 CI(windows-latest)의 WebView2 E2E로 확인한다. 실제 SMB·WebDAV 서버 연결과 로그인 창은 이 환경에서 확인하지 못했다.
