# v0.7.4 오류 수정과 배포 안내

Windows와 macOS에서 보고된 경로·파일 작업·스크롤·한글 입력 문제를 수정한 버전이다. 기존 앱을 트레이 메뉴의 **완전히 종료**로 끝낸 뒤 새 버전으로 교체한다. 인덱스와 즐겨찾기 등 사용자 데이터는 별도로 보관되므로 앱 교체 후 다시 사용할 수 있다.

## 변경 사항

- Windows 내부 긴 경로 접두사 `\\?\`와 `\\?\UNC\`는 파일 시스템 접근에 유지하고 화면·경로 복사에는 일반 경로로 표시한다.
- Windows의 파일 위치 열기는 Shell API로 항목을 선택한다. 폴더의 탐색기 보기는 해당 폴더를 직접 연다. 공백·한글·쉼표가 있는 이름을 명령행으로 조립하지 않는다.
- 메인 탐색창 복사는 운영체제 파일 클립보드에도 기록한다. Finder·Windows 탐색기에서 복사한 파일을 앱에 붙여넣을 수 있다. 외부 파일은 사본으로 가져오고 기존 파일과 이름이 겹치면 원본을 덮어쓰지 않고 안내한다. 앱 내부 잘라내기는 OS 클립보드의 항목과 일치할 때만 이동한다.
- 폴더 속성은 인덱스의 크기와 항목 수를 즉시 합산하고 기준 시각을 표시한다. 디스크 전체를 다시 순회하거나 다른 긴 복사 작업의 잠금을 기다리지 않는다. SHA-256은 별도로 요청할 때만 계산한다.
- 목록 갱신과 파일 선택 유지 중 스크롤을 보존한다. 실제 위치·필터·정렬이 바뀔 때 목록의 처음으로 이동한다.
- 기본 검색은 **초성 + 일반 검색**이다. `ㅂㄱㅅ`, `보고서`, `Report`, `보고ㅅ`, `*.pdf`를 한 모드에서 처리한다. 일반 단어의 음절은 그대로 비교해 잘못된 초성 확장을 방지한다. IME가 `ㄱㅅ`을 `ㄳ`으로 합치면 개별 초성으로 정규화하며 완성형 단어는 보존한다.
- 설정과 트레이 메뉴에서 자동 시작, 트레이 시작, 창을 닫아도 계속 실행, 기본 검색 방식과 전역 검색 단축키를 설정한다. 로그인 자동 시작은 기본 켜짐이며 실패 시 오류를 표시한다. 검증용 격리 실행은 실제 로그인 항목을 변경하지 않는다.
- 설정에 개발자 정보 등록 상태와 npm·Rust 의존성의 오픈소스 라이선스를 표시한다. 현재 프로젝트에는 개발자명·연락처와 앱 자체 이용 허락 문서가 등록되지 않아 미지정으로 표시한다.
- 탭 옆 색상 버튼에서 각 탭의 색을 바꾸며 작업 공간에 저장한다. 색상 버튼을 오른쪽 클릭하면 기본색으로 돌아간다.
- 연결 폴더가 없는 첫 실행은 폴더 설정 안내와 함께 인덱스 관리 화면을 연다.

## 설치 파일

- macOS 11 이상 Apple Silicon: [DMG 설치 이미지](EveryDirectory_0.7.4_mac_arm64.dmg), [ZIP 압축본](EveryDirectory_0.7.4_mac_arm64.zip). 앱을 Applications로 옮긴 뒤 실행한다. Intel Mac 전용 빌드는 포함하지 않는다.
- Windows 10·11 x64: [경량 설치 EXE](EveryDirectory_0.7.4_windows_x64_lite_setup.exe), **2.63MiB**. **WebView2 런타임 설치본은 포함하지 않으며 다운로드도 시도하지 않는다.** PC에 설치된 Evergreen WebView2를 사용한다. 런타임이 없으면 설치 전에 필요한 준비를 안내한다.

Mac은 로컬 임시 서명 상태이며 Apple Developer ID 서명·공증은 적용하지 않았다. Windows 설치 파일은 서명하지 않았다.

## 검증 범위

Node 34개와 Rust 34개 회귀 테스트를 통과했다. Mac의 실제 네이티브 WebView에서 첫 실행 안내, 일반·초성 검색, 합쳐진 자음 분리, 갱신 후 스크롤 유지, 화면 복사·붙여넣기, 잘라내기 이동, 속성 조회, 탭 색상 저장과 설정 저장을 확인했다. 파일 작업 후 원본과 결과의 SHA-256도 일치했다. 검증 빌드는 사용자 설정과 자동 시작 등록을 격리한다.

20만 항목의 릴리스 엔진 벤치마크에서는 일반 검색 4.07ms, 초성 통합 검색 6.60ms였다. 이는 특정 테스트 데이터의 엔진 측정값이며 실제 디스크 인덱싱 시간이나 모든 검색의 지연을 보장하지 않는다.

Windows 설치 EXE의 압축 무결성·x64 형식·0.7.4 버전과 런타임 미포함을 확인했다. Mac ZIP·DMG의 압축/디스크 이미지 무결성과 임시 서명을 검증했고 두 패키지의 실행 파일이 일치했다. 설치 파일별 크기와 SHA-256은 배포 폴더의 `artifacts.json`, 무결성 확인은 `SHA256SUMS.txt`, 상세 결과는 `verification.json`을 사용한다. 오픈소스 고지와 라이선스 전문은 `THIRD_PARTY_NOTICES.txt`와 설정 화면에서 확인한다.

Windows 실기기의 Explorer 이동·클립보드 붙여넣기·한국어 IME, 로그인 후 자동 시작과 회사 정책 적용은 별도 실기 확인 항목이다. Mac도 물리 키보드 전역 단축키·다중 Spaces·실제 로그아웃 후 자동 시작은 별도 확인 항목이다. 합성 입력 검증은 실제 Windows IME 검증과 동일하지 않다.

관련 구현은 [Microsoft Shell API](https://learn.microsoft.com/en-us/windows/win32/api/shlobj_core/nf-shlobj_core-shopenfolderandselectitems)와 [Tauri 자동 시작 플러그인](https://v2.tauri.app/plugin/autostart/)을 따른다.
