# 검색 영역 접기·펼치기

탐색창은 늘 쓰지만 검색은 필요할 때만 씁니다. 그래서 검색 영역을 쉽게 접고 펼 수 있게 했습니다. 접는 것은 "닫기"가 아니라 "접기"입니다. 검색어·결과·선택·스크롤·열 너비·크기 비율은 그대로 남고, 다시 펼치면 검색을 새로 돌리지 않고 바로 보입니다.

## 켜고 끄는 곳

| 위치 | 동작 |
|---|---|
| 상단 도구 막대 맨 앞 **검색** 스위치 | 누를 때마다 보이기/숨기기 전환. 켜짐은 강조색 채움과 오른쪽으로 간 스위치, 꺼짐은 테두리만 표시합니다. 좁은 창에서도 글자를 숨기지 않습니다. |
| 검색 입력 줄 오른쪽 숨기기 단추 | 검색 영역을 접습니다. 아이콘은 검색 영역 위치(왼쪽·오른쪽·위·아래)에 맞춰 바뀝니다. |
| 접었을 때 가장자리의 **검색 열기** 띠 | 검색이 있던 쪽에 남는 띠입니다. 누르면 펼치고 입력칸으로 갑니다. 검색어가 있으면 결과 개수를 함께 표시합니다. |
| **Ctrl/⌘ + Shift + F** | 보이기/숨기기 전환 |
| 레이아웃 메뉴 **검색 영역 표시** 스위치, 명령 팔레트 **검색 영역 숨기기/보이기** | 같은 전환 |

## 필요할 때 자동으로 펼치기

Ctrl/⌘ K, 탐색창 밖의 Ctrl/⌘ F, F3, 트레이 메뉴의 검색, 로고, 사이드바의 **검색 및 탐색**을 누르면 접힌 검색 영역을 펼치고 입력칸에 초점을 둡니다. 이 동작들은 열기만 하고 숨기지는 않습니다. 탐색창 안의 Ctrl/⌘ F는 지금처럼 현재 폴더 필터입니다.

## 품질 유지

- 숨긴 검색 영역은 화면에서만 빼고(`display:none`, `inert`) 컴포넌트는 그대로 둡니다.
- 검색 안에 초점이 있을 때 접으면, 먼저 활성 탐색창의 선택 항목으로 초점을 옮깁니다.
- 접힌 동안 Tab/Shift+Tab은 탐색창끼리만 돕니다.
- 크기 조절 손잡이는 접힌 동안 숨기고, 펼치면 이전 비율로 돌아옵니다.
- 표시 상태는 위치·비율과 함께 저장해 다시 실행해도 유지하고, 저장한 작업 공간에도 담습니다. **기본 레이아웃으로 돌아가기**는 검색 영역을 다시 표시합니다. 기본값은 표시입니다.
- 머리글의 빠른 검색 창 단추는 별도 작은 창을 여는 기능이라, 검색 영역 스위치와 헷갈리지 않게 아이콘을 `ScanSearch`로 바꿨습니다.

## 검증

- ux E2E 스위트 3-2절: 스위치 위치와 기본 켜짐, Ctrl/⌘+Shift+F로 접기, 탐색창이 넓어지는지, 초점 이동, 띠의 결과 개수, 저장, 접힌 동안 Tab 순환, 띠로 펼친 뒤 검색어·결과·선택 유지, 숨기기 단추와 Ctrl/⌘+K, 도구 막대 스위치를 확인합니다.
- 웹 미리보기에서 라이트·다크 테마, 왼쪽·오른쪽·위쪽 위치, 1400·1000·760px 너비를 확인했습니다.
