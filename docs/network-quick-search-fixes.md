# 네트워크 폴더 주기 확인·빠른 검색 경로 입력 결함 수정

0.12.1 이후 전체 점검에서 확인한 결함을 고쳤다. 버전 번호는 아직 올리지 않았다.

## 네트워크 폴더 주기 확인

- **다시 색인할 때마다 주기 확인 스레드가 늘어나던 문제**
  - 원인: 연결 폴더를 다시 색인할 때마다 감시 시작 함수가 주기 확인 스레드를 새로 띄웠다.
  - 해결: 주기 확인 중인 연결 폴더 id를 기록해 폴더마다 스레드를 하나만 둔다.
- **첫 색인이 5분을 넘으면 주기 확인이 꺼지던 문제**
  - 원인: 주기 확인 스레드는 색인 완료 전에 시작한다. 5분 뒤 아직 등록되지 않은 연결 폴더를 보고 "연결이 해제됐다"며 끝냈다.
  - 해결: 스레드는 연결을 해제했을 때만 끝난다. 첫 색인 중이면 다음 차례에 다시 확인한다. 색인 작업이 없는데도 연결 폴더가 없으면(첫 색인 실패) 끝낸다.
- **공유 폴더를 다시 읽는 동안 파일 작업이 모두 멈추던 문제**
  - 원인: 공유 폴더 전체를 다시 읽는 내내 파일 작업 잠금을 잡고 있었다.
  - 해결: 다시 읽기는 잠금 없이 하고, 반영할 때만 잠깐 잠금을 잡는다.
  - 읽는 사이 같은 폴더의 색인이 바뀌었으면(파일 작업·실시간 알림) 낡은 결과로 덮지 않고 다음 차례에 다시 읽는다.
- **읽는 도중 연결이 끊기면 항목이 지워지던 문제**: 다시 읽은 뒤에도 공유 폴더에 연결되어 있는지 확인한다. 끊겼으면 읽은 결과를 버리고 "연결할 수 없음"으로 표시한다. 읽지 못한 하위 폴더가 삭제된 것으로 처리되지 않는다.
- **끊긴 공유 폴더 하나 때문에 다른 폴더의 감시 시작이 기다리던 문제**: 운영체제 감시를 등록하는 동안 감시 목록 잠금을 놓는다.
- **처음 연결하다 저장에 실패하면 감시가 남던 문제**: 미리 시작한 감시와 주기 확인을 거둔다.

## 빠른 검색 경로 입력

- **`/`·`\`가 들어간 입력이 모두 경로 이동으로 처리되던 문제**
  - 정규식 검색의 `\d{4}` 같은 입력은 경로로 보지 않고 정규식 그대로 검색한다.
  - 초성 경로(`ㅇㅁ/ㅂㄱㅅ`)는 초성 검색으로 경로 전체에서 찾는다. 이전에는 일반 검색으로 바뀌어 결과가 없었다.
  - 그 밖의 경로 입력은 이전처럼 `*`·`?`를 이해하는 일반 검색으로 찾는다.
- **검색어를 지워도 "경로 일치 · Enter 이동" 표시가 남던 문제**: 검색어를 지우거나 검색에 실패하면 경로 일치 표시를 지운다. 그때 Enter를 누르면 이동이 아니라 열기가 실행된다.
- **Windows에서 하위 폴더의 대소문자가 다르면 경로를 찾지 못하던 문제**: 색인에 저장된 실제 표기를 대소문자와 상관없이 찾는다. 예를 들어 `reports`로 `Reports` 폴더를 찾는다.
- **경로만 일치하는 항목을 놓치던 문제**: 0.12.1부터 빠른 경로 검색은 파일명 색인으로 파일명 일치를 먼저 찾는다. 그러나 정규식·퍼지·한두 글자 검색은 파일명 색인으로 좁힐 수 없다. 이런 검색에서는 파일명 단계가 시간 제한(250ms)을 다 써서 경로 단계가 돌지 못했다. 이제 이런 검색은 경로 검색 한 번으로 찾는다. 경로에는 파일명도 들어 있다.

## 네트워크 주소의 사용자 이름

- `smb://사용자@서버/공유`에 적은 사용자 이름을 더 이상 버리지 않는다.
  - macOS: 사용자 이름을 넣은 주소로 연결한다. `도메인;사용자` 표기도 된다.
  - Windows: 그 사용자 이름으로 로그인 창을 띄운다.
- 비밀번호가 든 주소는 이전처럼 받지 않는다.

## 웹 버전 색인을 데스크톱에서 열 때

- 웹 버전이 `\\서버\공유`로 저장한 연결 폴더는 실제 경로 표기(`\\?\UNC\서버\공유`)가 달라 "연결 폴더 밖" 오류가 날 수 있었다.
- 첫 비교가 실패하면 기준 경로도 실제 경로로 바꿔 다시 비교한다.

## 검증

- 단위 테스트
  - 경로 입력 검색 방식(정규식 제외, 초성 유지).
  - 네트워크 주소의 사용자 이름(디코딩, macOS 주소, UNC 변환).
  - 20만·100만 항목에서 경로에만 일치하는 한 글자 빠른 검색(`업`): 100만 항목에서 21ms, 전체 확인.
- 실제 앱 E2E(macOS): 전체 스위트.
- 검증하지 못한 것
  - Windows 전용 동작(대소문자 경로, 사용자 이름이 든 로그인 창, UNC 비교)은 macOS에서 Windows 대상으로 컴파일·정적 분석만 했다. Windows 실기 확인이 필요하다.
  - 네트워크 공유 주기 확인은 실제 NAS 없이 코드 검토와 컴파일로만 확인했다.
