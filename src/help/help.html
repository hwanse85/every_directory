시작하기

Every Directory는 연결한 폴더 전체를 미리 색인해 즉시 찾고, 찾은 파일을 여러 탐색창에서 바로 다루는 파일 관리 프로그램입니다. 검색 → 위치 확인 → 복사·이동·이름 바꾸기를 한 화면에서 끝냅니다.

  1. 폴더 연결 — 사이드바의 폴더 연결을 눌러 검색할 폴더를 고릅니다. 하위 폴더까지 색인하며, 처음 한 번만 시간이 걸립니다.
  2. 검색 — 위쪽 검색 입력칸에 이름 일부를 입력합니다. 입력하는 즉시 결과가 바뀝니다.
  3. 작업 — 결과를 한 번 누르면 선택, 두 번 누르면 기본 앱으로 엽니다. 위치에서 이어서 작업하려면 +Enter나 새 탭에서 열기를 씁니다.
가장 먼저 기억할 단축키 F1 도움말 · +K 검색 입력칸 · +Shift+P 명령 찾기 · F2 이름 바꾸기

화면 구성

사이드바
연결 폴더, 즐겨찾기, 저장한 검색 조건·작업 공간, 설정과 도움말이 있습니다.
검색 영역
검색 입력칸, 검색 방식, 검색할 폴더, 파일 종류 필터와 결과 목록입니다. 필요 없을 때는 접어 둘 수 있습니다.
탐색창
기본 두 개이며 1~4개로 바꿀 수 있습니다. 창마다 여러 탭을 열고, 테두리가 굵게 강조된 창이 활성 탐색창입니다.
도구 막대
탐색창 위쪽의 새 폴더·복사·잘라내기·붙여넣기·이름 바꾸기·삭제·압축 단추입니다. 창이 좁으면 아이콘만 보입니다.
편의 아이콘
상단의 검색·도구·레이아웃·탐색창(기본 아이콘) 뒤에 있는 아이콘 묶음입니다. 아래 편의 아이콘 고르기를 보세요.

편의 아이콘 고르기

기본으로 새 탭·새 폴더·새로 고침·클립보드 이력·UU 인코딩·UU 디코딩이 놓여 있습니다. 오른쪽 끝 연필 단추(또는 아이콘 위에서 우클릭)로 편집합니다.

  • 추가·삭제: 목록의 체크 상자를 켜고 끕니다. 홈 폴더 열기, 숨김 파일 전환, 다른 탐색창으로 복사, 폴더 비교, 용량 분석, 중복 파일, 일괄 이름 변경, 터미널, 앱 휴지통, 빠른 검색 창, 명령 찾기도 고를 수 있습니다.
  • 순서: ↑ ↓ 단추로 한 칸씩 옮깁니다. 기본 아이콘으로 되돌리기로 처음 구성으로 돌아갑니다.
  • 구성은 저장되어 다시 실행해도 유지됩니다.
  • 창이 좁아 다 들어가지 않으면 연필 단추에 +숫자가 붙고, 숨은 아이콘은 그 팝업 맨 위에서 바로 실행합니다.
  • 아이콘은 활성 탐색창과 그 선택 항목을 기준으로 실행됩니다.

검색 영역 접고 펴기

상단 도구 막대 맨 앞의 검색 스위치, 검색 입력 줄 오른쪽의 숨기기 단추, 또는 +Shift+F로 접고 폅니다. 접으면 탐색창이 자리를 모두 쓰고, 검색이 있던 가장자리에 검색 열기 띠가 남습니다. 접어도 검색어·결과·선택은 그대로입니다.

레이아웃

레이아웃 메뉴에서 검색 영역 위치(왼쪽·오른쪽·위·아래), 탐색창 개수와 배치, 크기 비율을 바꿉니다. 경계선을 끌거나, 경계선에 초점을 두고 방향키로 조절할 수도 있습니다.

검색하기

검색은 연결한 모든 폴더(또는 검색할 폴더에서 고른 폴더 하나)의 색인을 대상으로 합니다. 기본은 파일 이름에서 찾고, 설정의 전체 경로에서 검색을 켜면 폴더 경로까지 봅니다.

  • 입력하면 잠시 뒤(설정의 검색 입력 대기) 자동으로 검색합니다. Enter를 누를 필요가 없습니다.
  • 검색어와 일치한 글자는 결과에서 강조됩니다(설정에서 끌 수 있음).
  • 종류 필터(문서·이미지·음악·동영상·압축 등)로 결과를 좁힐 수 있습니다.
  • 대소문자를 켜면 영문 대소문자를 구분합니다. 초성 검색에서는 쓰지 않습니다.

초성 + 일반

  • ㅂㄱㅅ는 ‘보고서’, ㅆㄹㅁㅇㄷ는 ‘쏠리마인드’를 찾습니다. 된소리·겹받침도 됩니다.
  • 초성과 글자를 섞어도 됩니다: 보고ㅅ, ㅇㅁ 보고서.
  • 초성이 아닌 글자는 일반 검색과 같이 ‘포함’으로 찾습니다. 공백은 AND입니다.

일반

입력한 글자가 이름 어딘가에 들어 있으면 찾습니다. 공백으로 나눈 단어는 모두 들어 있어야 합니다. 아래 검색 연산자를 함께 쓸 수 있습니다.

와일드카드

  • *는 0글자 이상, ?는 정확히 한 글자입니다.
  • 이름 전체와 비교합니다. 보고서만 입력하면 ‘업무 보고서.txt’는 찾지 않습니다. 앞뒤에 *를 붙이세요: *보고서*.
  • 대소문자는 대소문자를 켜지 않으면 구분하지 않습니다(*.pdf가 ‘A.PDF’도 찾음).
  • 일반 방식에서도 *, ?가 든 단어는 와일드카드로 해석합니다.

정규식

  • 입력 전체를 하나의 정규식으로 해석합니다(공백·|도 패턴의 일부입니다).
  • 자주 쓰는 표현: ^ 시작, $ 끝, \d 숫자, {4} 4번 반복, . 아무 글자, \. 점 자체, (a|b) 둘 중 하나, [가-힣] 한글 한 글자.
  • 예: \d{4}-\d{2}는 ‘회의록_2026-03.docx’, ^(?i)report는 Report로 시작하는 이름.
  • 전후방 탐색((?=…), (?<=…))과 역참조(\1)는 지원하지 않습니다. 잘못된 식은 결과 대신 오류 안내가 나옵니다.

퍼지

  • 오타를 허용합니다: 3~5글자 단어는 1글자, 6글자 이상은 2글자까지 틀려도 찾습니다.
  • 이름을 공백·점·밑줄·하이픈·괄호로 나눈 조각과 비교합니다. ‘회의룩’은 ‘회의록_2026-03.docx’를 찾습니다.
  • 정확히 들어 있는 결과를 먼저 보여 주고, 오타가 적은 순서로 이어집니다.
  • 2글자 이하는 오타를 허용하지 않고 포함 여부만 봅니다.

+Enter활성 탐색창의 새 탭에서 위치를 엽니다.

  • 결과는 한 번에 설정한 개수(기본 1,000개)씩 불러오고, 더 있으면 더 보기로 이어 불러옵니다.
  • ☆ 단추로 검색 조건을 저장해 사이드바에서 다시 불러옵니다. 탐색창·탭 조합은 작업 공간으로 저장합니다.
  • 내보내기 단추로 결과를 CSV·TXT·TSV·인쇄용 HTML로 저장합니다.

탐색창

폴더 이동

  • 폴더를 두 번 누르거나 Enter로 들어가고, Backspace나 Alt+↑로 상위 폴더로 갑니다.
  • Alt+←/→ 뒤로·앞으로. 위쪽 경로 조각을 눌러 바로 이동합니다.
  • 경로를 직접 입력하려면 경로 칸을 두 번 누르거나 +L, Alt+D, F4를 누릅니다.
  • 목록에서 글자를 바로 입력하면 그 글자로 시작하는 항목으로 이동합니다(초성도 됩니다).

탭

  • +T 새 탭, +W 닫기, Ctrl+Tab 다음 탭, Ctrl+Shift+T 닫은 탭 다시 열기.
  • 탭을 두 번 누르면 그 자리에서 탭 이름을 바꿉니다(Enter 저장 · Esc 취소 · 비우면 폴더 이름).
  • 탭 우클릭 메뉴: 복제, 이름 변경, 고정(고정 탭은 닫히지 않고 다른 위치는 새 탭에서 엽니다), 다른 탭 닫기.
  • 탭의 팔레트 단추로 색을 지정해 업무별로 구분합니다. 탭은 끌어서 순서를 바꿉니다.

보기·정렬·필터

  • 보기: 자세히·간단히·내용·타일·아이콘(작은~아주 큰). 표시할 속성 열도 고릅니다.
  • 정렬: 이름·크기·수정일 등과 오름/내림차순, 분류(그룹)로 묶어 보기.
  • 현재 폴더 필터: 경로 칸 오른쪽 입력칸 또는 탐색창 안에서 +F. 초성도 됩니다. Esc로 해제.
  • 숨김 파일 표시는 +Shift+.로 이 탐색창에서만 잠시 바꿀 수 있습니다.

이 PC: 색인하지 않은 위치도 탐색

탐색창은 연결(색인)한 폴더뿐 아니라 컴퓨터의 모든 경로를 열 수 있습니다. 예를 들어 D 드라이브만 연결했어도 C 드라이브를 탐색할 수 있습니다.

  • 사이드바의 이 PC에 홈 폴더와 드라이브(C:, D: …이 Mac(/), 외장·네트워크 볼륨)가 있습니다. 폴더 트리에도 함께 보입니다.
  • 주소 칸에 아무 경로나 입력해도 엽니다. 연결한 폴더 안의 경로면 그 연결 폴더로, 아니면 이 PC 위치로 엽니다.
  • 복사·이동·이름 바꾸기·새 폴더·압축·UU 인코딩 등 파일 작업을 똑같이 쓸 수 있고, 연결 폴더와 서로 복사·이동할 수 있습니다.
  • 이 PC 위치는 검색 대상이 아닙니다. 자주 찾는 폴더는 연결해 색인하세요.
  • 이 PC 위치에서 지운 항목은 앱 휴지통이 아니라 Windows 휴지통macOS 휴지통으로 갑니다. 드라이브·홈 폴더 자체는 지울 수 없습니다.
  • 드라이브를 꽂거나 빼면 창으로 돌아올 때 목록이 갱신됩니다.

여러 탐색창

클릭하거나 F6으로 활성 탐색창을 바꿉니다. 검색 결과의 위치 열기, 명령 팔레트, 붙여넣기는 활성 탐색창을 기준으로 동작합니다. 파일을 다른 탐색창이나 폴더로 끌어 놓으면 복사할지 이동할지 고르는 창이 뜹니다. 탐색기·Finder에서 끌어 온 파일은 원본을 두고 복사합니다.

폴더 트리

탐색창 도구 막대의 트리 단추로 왼쪽에 폴더 트리를 켭니다. 탐색창마다 따로 켜고 끄며, 현재 폴더까지 자동으로 펼치고 표시합니다.

  • 폴더를 누르면 이동, +클릭이나 가운데 클릭은 새 탭에서 엽니다.
  • 키보드: ↑/↓ 이동, → 펼치기, ← 접기·상위로, Enter 열기.
  • 깊은 폴더일수록 들여쓰기 간격을 점점 줄이고 세로 안내선으로 단계를 보여 줍니다. 그래서 깊이 들어가도 폴더 이름이 트리 안에 보입니다.
  • 트리 오른쪽 경계선을 끌어 너비를 바꾸고, 두 번 누르면 기본 너비로 돌아갑니다. 너비는 탐색창별로 저장됩니다.
  • 잘린 이름은 마우스를 올리면 전체 이름이 보입니다.

UU 인코딩 · 디코딩우클릭 → 파일 도구, 또는 상단 편의 아이콘아래 설명을 보세요.
속성 · 크기Alt+Enter 또는 +I폴더 크기·항목 수, 파일 SHA-256을 확인합니다.
일괄 이름 변경여러 개 선택 → 우클릭 → 일괄 이름 변경찾기/바꾸기(정규식 $1 가능)·접두사·접미사·번호를 미리보기로 확인하고 적용합니다.
이미지 크기·형식 변환, 텍스트 추출파일 도구원본은 두고 새 폴더에 결과를 만듭니다.
앱 밖으로 끌어 놓기파일을 프로그램 창 밖으로 끌기메일·브라우저 업로드 칸·탐색기·Finder에 복사로 놓입니다.

모든 작업은 연결 폴더 밖이나 연결 폴더 자체를 바꾸지 않고, 기존 파일을 덮어쓰지 않습니다.

이름 바꾸기·새로 만들기

이름을 묻는 창이 뜨지 않습니다. 목록의 그 행에서 바로 이름을 입력합니다.

  1. 항목을 고르고 F2(또는 우클릭 → 이름 변경, 도구 막대의 연필 단추)를 누릅니다.
  2. 이름 칸이 열리고 확장자 앞까지 선택됩니다. 바로 입력하면 이름만 바뀝니다.
  3. Enter나 Tab, 또는 다른 곳을 누르면 적용, Esc는 취소입니다.
  • 다른 파일의 이름을 복사해 붙여넣어도 됩니다: F2 → +C → Esc → 다른 파일에서 F2 → +V.
  • 다른 프로그램으로 잠시 가서 이름을 복사해 와도 편집이 유지됩니다.
  • 같은 이름이 있거나 쓸 수 없는 문자(\ / : * ? " < > |)·예약 이름(CON 등)이면 칸이 빨갛게 바뀌고 이유가 보입니다. 고치거나 Esc로 취소하세요.
  • 새 폴더(+Shift+N), 새 텍스트 파일, ZIP 압축, 압축 풀기는 ‘새 폴더’, ‘새 폴더 (2)’처럼 겹치지 않는 이름으로 바로 만든 뒤 그 행에서 이름을 받습니다.
  • 우클릭 → 새로 만들기 → Windows 새로 만들기는 PC에 등록된 형식(Word·Excel 등)으로 만들고, 하나를 만들면 바로 이름을 입력하게 합니다.
  • 검색 결과에서도 F2로 같은 방식으로 바꿉니다.

UU 인코딩·디코딩

파일을 글자만으로 된 텍스트(uuencode)로 바꾸거나, 그 텍스트를 원래 파일로 되돌립니다. 첨부 파일을 보낼 수 없는 메일·메신저·텍스트 전용 시스템으로 파일을 옮길 때 씁니다. sfk의 uuencode / uudecode와 같은 형식(begin 644 이름 … end)입니다.

  1. 파일이나 폴더 하나를 고르고 우클릭 → 파일 도구 → UU 인코딩(uuencode)…을 누릅니다(상단 편의 아이콘으로도 됩니다).
  2. 만들 파일 이름을 확인합니다. 기본은 원래이름.uue입니다.
  3. 백그라운드에서 인코딩 시작을 누르면 창이 닫히고, 프로그램 아래 상태 막대에 진행률이 보입니다. 그동안 다른 작업을 계속할 수 있습니다.
  • 폴더는 ZIP 하나로 묶은 뒤 인코딩합니다(폴더.zip.uue). 디코딩하면 ZIP이 나오고, ZIP 압축 풀기로 폴더를 되살립니다.
  • 디코딩: .uue 파일을 고르고 UU 디코딩(uudecode)…. 기본 이름은 .uue를 뗀 이름입니다. 메일 머리글처럼 begin 앞뒤에 있는 다른 글은 건너뜁니다.
  • 결과 파일은 원본과 같은 폴더에 만들어지고, 같은 이름이 있으면 덮어쓰지 않고 멈춥니다.
  • 상태 막대의 취소를 누르면 바로 멈추고 만들던 파일은 지웁니다. uuencode가 아닌 파일을 디코딩하면 이유를 빨간색으로 알려 줍니다.
  • 인코딩하면 크기가 약 1.4배가 됩니다.

빠른 검색 창

어느 프로그램을 쓰고 있든 전역 단축키(기본 +Shift+Space, 설정에서 변경)로 작은 검색 창을 띄웁니다. 트레이(메뉴 막대) 아이콘의 빠른 파일 검색으로도 엽니다.

  • 입력에 따라 초성·와일드카드·일반을 자동으로 고릅니다. 기본 검색 방식은 설정에서 정합니다.
  • ↑/↓ 선택, Enter 열기, Tab 작업 목록(파일 복사, 전체 경로 복사 +Shift+C, 다른 폴더로 복사, Every Directory에서 위치 열기, 즐겨찾기), Esc 닫기.
  • 절대 경로나 ‘연결 폴더 이름/하위 경로’를 입력하면 그 위치가 맨 위에 경로 일치로 나오고, Enter로 그 폴더를 엽니다.
  • 검색어가 없으면 즐겨찾기와 최근에 연 항목을 보여 줍니다.
클립보드 이력 열기 빠른 검색 창에 clip, 클립, 클립보드(또는 설정에서 정한 키워드)를 입력하면 결과 맨 위에 클립보드 보기가 나옵니다. Enter를 누르면 이력이 열립니다.

클립보드 이력

프로그램이 실행되는 동안 복사한 텍스트·이미지(화면 캡처)·파일을 이 PC에 기록해 다시 씁니다. 빠른 검색 창(clip·클립·클립보드)이나 도구 → 클립보드 탭에서 엽니다.

종류 탭전체·텍스트·이미지·파일·즐겨찾기. +1~5로 바꿉니다.
클립보드로 복사고른 이력을 원래 형태로 시스템 클립보드에 되돌립니다. 이미지는 이미지로, 파일은 파일로 복사되어 탐색기·Finder·다른 앱에 바로 붙여넣을 수 있습니다. Enter나 두 번 클릭도 같습니다.
텍스트로 복사파일 이력의 경로나 텍스트를 글자로 복사합니다(이미지는 해당 없음).
사본 저장텍스트는 .txt, 이미지는 .png 파일로, 파일 이력은 고른 폴더에 사본으로 저장합니다. 기존 파일은 덮어쓰지 않습니다.
즐겨찾기 · 삭제자주 쓰는 내용을 표시하고, Delete로 지웁니다. 전체 이력 삭제는 한 번 더 확인합니다.
찾기+F. 목록에 보이지 않는 긴 텍스트의 본문까지 찾습니다.
  • 보관 기간(기본 10일), 기록할 종류, 항목당 최대 크기, 기록하지 않을 앱은 설정 → 사용자 설정에서 정합니다. 전체 이력은 최대 200 MB / 2,000개입니다.
  • 비밀번호 관리자처럼 기록 금지 표시를 단 내용은 저장하지 않습니다.
  • 파일 이력은 원본 위치만 기록합니다. 원본을 옮기거나 지우면 복원할 수 없습니다.

설정

사이드바의 설정에서 엽니다. 바꾼 뒤 아래쪽의 사용자 설정 저장을 누르세요. 저장하지 않고 닫으면 저장 여부를 묻습니다.

  • 표시: 숨김 파일·임시·잠금 파일·휴지통 항목 표시, 검색어 매칭 강조, 파일 목록 글자 크기, 파일 목록 밀도, 파일 종류별 색상, 화면 테마, 활성 탐색창 강조 색, 새 탐색창 기본 보기.
  • 검색: 기본 검색 방식, 전체 경로에서 검색, 검색 입력 대기, 한 번에 불러올 결과 수, 검색 결과 선택 시 탐색창 따라가기, 빠른 검색에서 경로도 검색.
  • 실행: 전역 검색 단축키, 창을 닫아도 계속 실행(트레이), 로그인 시 자동 시작, 트레이에서 시작.
  • 연결 폴더: 다시 색인, 연결 해제, 인덱스 제외 폴더(검색에서만 빼고 탐색은 계속 가능), 네트워크·웹 드라이브(SMB·WebDAV) 연결.

포터블 판은 실행 파일 옆 portable-data 폴더에 설정과 색인을 저장합니다.

문제 해결

방금 만든 파일이 검색되지 않아요.
연결 폴더의 변경은 자동으로 반영되지만, 네트워크 드라이브는 주기적으로 확인하므로 조금 늦을 수 있습니다. 사이드바에서 그 연결 폴더를 다시 색인하세요.
숨김 파일이나 ~$로 시작하는 파일이 보이지 않아요.
기본으로 숨김·임시·잠금 파일과 휴지통 항목은 감춥니다. 설정에서 표시를 켜거나, 탐색창에서 +Shift+.를 누르세요.
정규식이 오류로 나와요.
괄호·대괄호 짝을 확인하세요. 전후방 탐색과 역참조는 지원하지 않습니다. 단순한 모양이면 와일드카드가 더 쉽습니다.
검색 결과가 너무 많아요.
단어를 더 넣거나(AND), ext:, !제외, 종류 필터, 검색할 폴더로 좁히세요.
전역 단축키가 동작하지 않아요.
다른 프로그램이 같은 단축키를 쓰고 있을 수 있습니다. 설정의 전역 검색 단축키에서 다른 조합으로 바꾸세요. 등록하지 못하면 설정 화면에 이유가 표시됩니다.
연결하지 않은 드라이브(예: C:)를 보고 싶어요.
사이드바의 이 PC에서 드라이브를 누르거나 주소 칸에 경로를 입력하세요. 색인 없이 바로 열립니다. 다만 검색에는 나오지 않습니다.
삭제한 파일을 되살리고 싶어요.
파일 도구 → 앱 휴지통·복원에서 원래 위치로 복원합니다. 각 연결 폴더의 .every-directory-trash에 보관됩니다.
